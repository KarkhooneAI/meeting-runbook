# Fonts

Self-hosted brand fonts, both under the SIL Open Font License:

- **Vazir** — Persian body text (https://github.com/rastikerdar/vazir-font)
- **Tomorrow** — Latin text, brand name and numbers (https://fonts.google.com/specimen/Tomorrow)

Files expected here: `Vazir.ttf`, `Vazir-Medium.ttf`, `Vazir-Bold.ttf`, `Tomorrow-Regular.woff2`, `Tomorrow-Medium.woff2`, `Tomorrow-Bold.woff2`.
`fonts.css` declares the faces and is linked from `index.html`. If a file is missing the app silently falls back to system fonts.
